# Fondations de l'interface — plan de mise en œuvre

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poser le socle visuel commun (jetons, coquille, composants, Gyro, réglage d'affichage) et des tests d'accessibilité automatiques, puis y remettre la connexion et l'accueil.

**Architecture:** Les jetons sont des variables CSS dans `apps/web/src/app.css` ; le thème et le niveau de vie viennent de deux cookies lus par `hooks.server.ts`, qui les pose sur `<html>` avant l'envoi de la page. Les composants vivent dans `apps/web/src/lib/ui/` et `apps/web/src/lib/gyro/` ; leurs tests rendent le HTML côté serveur avec `render` de `svelte/server` (aucune dépendance de plus). Les tests d'accessibilité passent par Playwright et axe sur l'appli lancée en local.

**Tech Stack:** SvelteKit 3, Svelte 5, Vitest 5, `@fontsource/barlow` et `@fontsource/barlow-condensed`, `@playwright/test`, `@axe-core/playwright`.

**Spec:** `docs/superpowers/specs/2026-10-26-design-ui-design.md` (maquettes et dessin de Gyro dans `docs/superpowers/specs/2026-10-26-design-ui/`)

## Global Constraints

- RGAA, niveau AA des WCAG : contraste du texte ≥ 4,5:1 (≥ 3:1 au-delà de 24 px ou 18,66 px gras), cibles tactiles ≥ 44 px, texte agrandissable à 200 %, tout au clavier avec repère visible, jamais une information portée par la seule couleur.
- Téléphone (390 px) et ordinateur (1280 px) : chaque écran soigné aux deux tailles.
- Niveaux de vie `sobre` | `equilibre` | `vivant`, **`vivant` par défaut** ; thème `auto` | `clair` | `sombre`, **`auto` par défaut**.
- `prefers-reduced-motion: reduce` arrête toute animation décorative ; l'humour des textes reste.
- Ni humour ni animation sur les écrans d'urgence (aucun dans ce lot).
- CSP existante gardée (`apps/web/vite.config.ts`) : polices servies par l'appli, jamais par Google Fonts.
- Aucune porte dérobée de test dans le code de l'appli.
- Rien de propre à un centre dans le code ; vouvoiement ; français partout.
- Dépendances à versions exactes, justifiées dans la PR et dans `docs/technique/README.md`.
- Machine de 2 Go : commandes lourdes en cage (`systemd-run --user --scope -q -p MemoryMax=1100M -p MemorySwapMax=900M timeout 900 …`, `NODE_OPTIONS=--max-old-space-size=950` pour `pnpm check` d'`apps/web`), commit + push à chaque étape verte ; les tests Playwright tournent surtout en CI.

## Review Focus

1. Cookie de réglage absent, vide ou trafiqué (`niveau=<script>`) → valeurs par défaut, jamais réinjecté tel quel dans la page (Tâche 2).
2. Changement d'heure (fuseau Europe/Paris, fin octobre et fin mars) → la tenue du moment suit l'heure de Paris, pas celle du serveur (Tâche 5).
3. Navigation au clavier sur ordinateur et sur téléphone : le premier Tab atteint « Aller au contenu », l'entrée active porte `aria-current="page"` (Tâches 3 et 7).
4. Mode sombre forcé alors que le téléphone est clair (et l'inverse) → le choix de l'agent gagne, sans flash au chargement (Tâches 1 et 2).
5. Cinq touches sur Gyro au clavier (Entrée ou Espace) comptent comme cinq appuis ; « réduire les animations » garde le « pin-pon ! » écrit sans mouvement (Tâche 6).
