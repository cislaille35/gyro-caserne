# Engins, lot A : engins et fiches — plan

Spec : `docs/superpowers/specs/2026-11-02-engins-design.md` (lot A seulement). Méthode allégée de `CLAUDE.md`.

## Modèle (migration 0017, additive)

- `type_engin` (id, nom unique, ordre) : porte la fiche. VSAV, FPT, VTU au départ (noms du réglage d'armement).
- `fiche_version` (type, numéro, auteur, date, `utilisee`) : la fiche d'un type est sa dernière version. Une version pas encore utilisée se réécrit sur place ; une version utilisée (le lot B la marque à la première prise) est gardée telle quelle et la modification suivante en crée une nouvelle.
- `fiche_zone` (version, `ref`, nom, ordre) et `fiche_element` (version, zone, `ref`, libellé, quantité attendue ou rien, ordre). `ref` reste le même d'une version à l'autre : le lot C y accroche les anomalies, le fichier s'en sert comme « Réf. ».
- `engin` (nom, immatriculation, type, situation `centre` | `prete` | `parti`, provenance si prêté, état `disponible` | `indisponible`, ordre, parti le). L'avertissement viendra des anomalies (lot C) ; l'état est écrit par le lot C.
- Fiches de départ : constante `FICHES_PAR_DEFAUT` (reprise du MVP), posée par le jeu de départ et, pour les bases déjà remplies, par la migration (test d'égalité entre les deux).
- Droits : `VOIR_ENGINS` (profil Agent) voit ; `GERER_FICHES` (sur n'importe quel périmètre) gère engins et fiches. Le chef de garde reçoit `GERER_FICHES` et `TRAITER_ANOMALIE` (paquet « Engins : Gérer »), verrouillés, comme le chef de centre et l'adjoint ; le référent engins les a déjà.

2. **Socle** `engins.ts` : lire / enregistrer un engin (prêté, parti), lister ; `fiches.ts` : lire une fiche, gestes purs (zone et élément : ajouter, renommer, déplacer, retirer, changer de zone), écrire (sur place ou nouvelle version), journal ; `fichier-fiches.ts` : données du classeur (une feuille par type : Réf., Zone, Élément, Quantité), aperçu, application.
3. **Écrans engins** : Caserne → Engins (`/engins` : au centre, prêtés, partis repliés), page d'un engin (`/engins/[id]` : état, situation, sa fiche en zones repliables ; gestion dans un panneau), ajout.
4. **Éditeur de fiche** : `/engins/fiches` (types et fiches, nouveau type), `/engins/fiches/[id]` (zones repliables, gestes par élément).
5. **Fichier des fiches** : `/engins/fiches/fichier` (export, import avec aperçu, validation).
6. **Finitions** : engins fictifs (local, préprod), doc (fonctionnel, utilisation, technique, décision), chemins d'accessibilité en CI, test de parité, budget de requêtes.
