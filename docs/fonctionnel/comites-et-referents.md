# Comités et référents

## À quoi ça sert

Savoir à qui s'adresser : qui est dans quel comité, qui est référent de quoi, qui est chef de garde de chaque équipe. Une page de lecture, ouverte à tous les agents (Caserne → « Comités et référents »). Elle regroupe ce qui existe déjà (comités, rôles, nominations) ; rien ne s'y modifie.

## Ce qu'on y voit

**Comités** (en cours, pas les dissous), un bloc par comité :
- ses membres, avec leur rôle dans le comité (« Rapporteur », « Membre », ou le nom donné au rôle dans Réglages) ; le rapporteur d'abord ;
- « Aucun membre pour l'instant » s'il est vide ;
- le lien vers son mur, **seulement pour qui peut le lire** : ses membres, le chef de centre, l'adjoint et le super administrateur. Les autres ne voient pas de lien qui mènerait à un refus ;
- son matériel à réserver, s'il en gère (le barnum de l'amicale…) : un lien vers son calendrier pour qui peut le réserver ou le gère, le nom seul sinon.

**Référents et rôles**, rangés comme dans Réglages :
- « Chef de centre et adjoint » ;
- « Chefs de garde », une ligne par équipe active ;
- « Référents » (pharmacie, engins, technique…), chacun avec son icône.

Chaque rôle montre ses titulaires du jour, ou « Personne pour l'instant ». Les droits techniques ne sont pas affichés.

Sont comptés les agents qui ont accès à l'appli : ni partis, ni suspendus, ni comptes extérieurs (la réserve citoyenne), comme pour les murs. Un rôle nommé à l'avance n'apparaît qu'à sa date de début.

## Qui y entre

Tout agent qui a accès, et le super administrateur. Le compte partagé de la réserve citoyenne reçoit un refus.

Un lien « Gérer » en haut de la page : vers « Nominations » pour qui peut nommer à au moins un rôle, sinon vers « Réglages » pour qui règle les comités ou les rôles. Rien pour les autres.

## Exemple

Alice cherche qui commande le barnum pour la Sainte-Barbe. Caserne → « Comités et référents » : dans le bloc « Amicale », Bruno est rapporteur, et « Barnum » mène à son calendrier. Elle n'est pas de l'Amicale : pas de lien vers son mur.
