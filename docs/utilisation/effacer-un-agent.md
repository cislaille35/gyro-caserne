# Comment effacer les données d'un agent ?

Réservé au chef de centre, à son adjoint et au super administrateur. Sans rien faire, les données d'un agent parti s'effacent seules 12 mois après son départ ; ceci sert quand il demande l'effacement plus tôt.

1. Déclarez d'abord son départ s'il n'est pas parti : [Comment déclarer le départ d'un agent ?](declarer-un-depart.md).
2. Dans « Caserne », puis « Agents », filtrez sur « Partis » et appuyez sur son nom.
3. Ouvrez le bloc « Départ du centre », puis « Plus ».
4. Lisez ce qui sera perdu, cochez « Je confirme », puis appuyez sur « Effacer ses données ». Le message « Données effacées » apparaît.

C'est définitif. Son nom devient « Ancien agent » dans les publications, messages, demandes, prises de garde et anomalies. Il sort de la liste des agents. S'il revient au centre, ajoutez-le comme un nouvel agent.
