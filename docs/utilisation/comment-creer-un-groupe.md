# Comment créer un groupe ?

Ouvert à tout agent qui a la messagerie. Seuls les membres lisent le groupe.

1. Appuyez sur « Échanges », puis sur « Messages ».
2. Appuyez sur le crayon « Nouveau message », puis sur « Nouveau groupe ». Pour votre équipe ou un de vos comités, appuyez plutôt sur « Groupe avec l’équipe … » ou « Groupe avec … » dans « Pour vous » : ses membres sont déjà cochés.
3. Cochez les membres (2 à 60), puis appuyez sur « Suivant ».
4. Donnez un nom au groupe (60 caractères au plus) et choisissez une icône.
5. Appuyez sur « Créer ». Le groupe s'ouvre : écrivez le premier message.

Vous animez le groupe. Pour ajouter ou retirer des membres, ou nommer un autre animateur : appuyez sur le nom du groupe, en haut, puis sur « Ajouter des membres » ou sur « ⋯ » à côté d'un membre. Un nouveau membre lit tout ce qui a été dit avant lui.

Tout membre peut renommer le groupe (« Renommer ») et le quitter (« Quitter le groupe »).
