# Comment préparer l'année dans un fichier ?

Ouvert au chef de centre et à son adjoint (droit « Gérer le planning »).

1. Planning → « Préparer l'année » → « Exporter l'année ou importer un fichier ».
2. « Exporter l'année 2027 » : un classeur avec les onglets Semaines, Manœuvres, Vacances scolaires (et Été, une fois la répartition proposée). Une année vide donne le roulement calculé.
3. Modifiez-le dans Excel ou LibreOffice :
   - **Semaines** : l'équipe de chaque semaine (liste déroulante).
   - **Manœuvres** : une ligne sans « Réf. » ajoute une manœuvre ; effacer une ligne la retire. « Équipes » : « Toutes » ou les numéros, « 1, 3 ».
   - **Vacances scolaires** : nom, du, au.
   - **Été** : « X » quand l'agent est présent sur la plage.
4. Dans « Importer un fichier », choisissez le fichier : l'aperçu dit ce qui change (« 3 semaines changées, 2 manœuvres ajoutées… »), le tour des fêtes, et chaque erreur avec sa ligne.
5. « Valider » : tout est appliqué d'un coup. Une manœuvre déjà annoncée et retirée est marquée « Annulée » ; ses convoqués sont prévenus.

Les fériés sont calculés : ils ne sont pas dans le fichier.
