# Comment signaler un problème sur un engin ?

Hors prise de garde, un problème vu sur un engin se signale depuis sa page : il est déjà choisi. Depuis Anomalies, touchez **Signaler un problème** en haut, puis l'engin dans le formulaire.

1. Ouvrez **Caserne**, puis **Engins**, puis l'engin.
2. Touchez **Signaler un problème**.
3. Dans « Le problème », écrivez-le en quelques mots (« Treuil hors service »). Dans « C’est » : Abîmé, Manquant ou À remplacer. Si utile : une note, « Ajouter une photo ».
4. Touchez **Signaler**.

L'engin reste disponible. Le référent engins et les chefs sont prévenus : eux seuls décident d'une indisponibilité. Vous êtes prévenu à chaque étape du suivi.
