# Comment signaler un problème sur un engin ?

Hors prise de garde, un problème vu sur un engin se signale depuis sa page : il est déjà choisi. Depuis Anomalies, touchez l'engin dans le formulaire.

1. Ouvrez **Caserne**, puis **Engins**, puis l'engin.
2. Touchez **Signaler un problème**.
3. Écrivez le problème en quelques mots (« Treuil hors service »). Si utile : abîmé, manquant ou à remplacer, une note, « Ajouter une photo ».
4. Touchez **Signaler**.

L'engin reste disponible. Le référent engins et les chefs sont prévenus : eux seuls décident d'une indisponibilité. Vous êtes prévenu à chaque étape du suivi.
