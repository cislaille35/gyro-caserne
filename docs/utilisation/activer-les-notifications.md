# Comment recevoir les notifications sur mon téléphone ?

1. Sur iPhone seulement : dans Safari, appuyez sur « Partager » (le carré avec une flèche), puis « Sur l'écran d'accueil » et « Ajouter ». Ouvrez ensuite Gyro Caserne depuis son icône (voir [Comment installer l'appli sur mon téléphone ?](installer-l-appli.md)).
2. Appuyez sur votre visage, en haut à droite, puis sur « Notifications ».
3. Appuyez sur « Activer sur ce téléphone », puis acceptez quand le téléphone demande l'autorisation.

Vous recevez alors les publications de vos murs, les commentaires sous les vôtres et vos messages. Faites-le sur chaque appareil où vous voulez les recevoir.

Si l'écran dit que les notifications sont bloquées : autorisez-les dans les réglages du téléphone (Notifications, Gyro Caserne), puis revenez à l'étape 2.
