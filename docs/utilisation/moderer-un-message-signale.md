# Comment traiter un message signalé ?

Réservé à la modération de la messagerie : le chef de centre, son adjoint, le super administrateur, et tout rôle qui modère la messagerie (Réglages, domaine « Messagerie »).

1. Appuyez sur la cloche, en haut à droite. Un message signalé compte dans son nombre.
2. En tête de la page, sous « Messages signalés » : le message, son auteur, sa date, et qui l'a signalé. Vous ne voyez que ce message, jamais le reste de la conversation.
3. Le message pose problème : appuyez sur « Retirer le message », puis sur « Retirer » pour confirmer. Il disparaît pour tous ; « Message retiré par la modération » reste à sa place.
4. Le message peut rester : appuyez sur « Classer ». Le message reste tel quel dans la conversation.

Dans les deux cas, le signalement disparaît de la liste. Si l'auteur a déjà supprimé son message, il ne reste qu'à le classer.
