# D'où vient la météo de l'Accueil ?

1. La ligne sous « Bonjour » donne le temps au centre, mis à jour toutes les heures par Open-Meteo.
2. Un bandeau orange ou rouge en haut de l'Accueil signale une vigilance Météo-France pour le département, aujourd'hui ou demain. Touchez « Consignes sur vigilance.meteofrance.fr » pour les détails.
3. En vigilance rouge, une notification arrive sur votre téléphone, une fois par épisode (si les notifications sont activées).
4. Pour couper l’animation de l’Accueil : Moi → Affichage, puis « Niveau de vie » : Sobre.

La météo est une information : elle ne remplace jamais une alerte du SDIS.
