# Comment répondre à une convocation ?

Ouvert à tout agent convoqué à un événement.

1. Ouvrez l'accueil : l'événement est dans « À ne pas manquer », rubrique « Événements ». La veille, il est marqué « Demain ».
2. Sous « Votre réponse », appuyez sur « Présent », « Absent » ou « Incertain ».
3. Votre réponse est cochée. Pour la changer, appuyez sur une autre.

Vous pouvez aussi répondre depuis le mur : appuyez sur « Échanges », ouvrez le mur, puis répondez sous la publication de l'événement.

Si l'événement a un sondage, appuyez sur « Sondage ouvert : votez sur la publication », puis sur votre réponse.

Vous ne voyez pas de boutons ? Vous n'êtes pas convoqué : l'événement ne concerne que les équipes indiquées dans « Convoqués ».
