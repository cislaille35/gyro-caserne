# Comment accepter ou refuser une demande de réservation ?

Pour les membres de l'amicale (matériel) et le référent engins (VL).

1. Touchez la notification, ou ouvrez la cloche : rubrique « À trancher », « … demandes de réservation à valider ». Elles sont aussi dans « À décider » de l'Accueil, sur votre casquette.
2. Sur « À valider », lisez la demande : qui, quoi, quand, et son mot.
3. Appuyez sur « Accepter ». Pour refuser : « Refuser », un motif si vous voulez, puis « Refuser la demande ».
4. VL déjà réservée sur ce créneau : choisissez « Garder cette demande » (l'autre réservation est annulée) ou « Garder l'autre ».

Le demandeur est prévenu. Pour annuler une réservation déjà acceptée : « À valider », rubrique « Acceptées à venir », « Annuler », un mot pour le demandeur si vous voulez, puis « Annuler la réservation ».

Pour ajouter du matériel, changer un stock ou retirer un objet : Réservations → « Gérer le matériel ».
