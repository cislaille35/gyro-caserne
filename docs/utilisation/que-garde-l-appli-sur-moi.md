# Que garde l'appli sur moi ?

1. Appuyez sur votre visage (« Moi »), puis sur « Vos données ». Sans être connecté : sur la page de connexion, appuyez sur « Vos données dans Gyro Caserne ».
2. La page dit ce qui est gardé, où (chez Cloudflare, dans l'Union européenne), qui le voit et combien de temps.
3. Pour corriger votre téléphone, votre surnom ou votre contact d'urgence : Moi › Mon profil.
4. Pour corriger autre chose, ou pour être effacé de l'appli : demandez au chef de centre.
