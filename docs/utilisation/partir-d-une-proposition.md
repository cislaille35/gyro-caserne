# Comment préparer l'année à partir de la précédente ?

Ouvert au chef de centre et à son adjoint (droit « Gérer le planning »), pour une année qui n'a pas encore de roulement.

1. Appuyez sur « Planning », puis « Préparer l'année ». Choisissez l'année en haut.
2. Appuyez sur « Partir d'une proposition ». Un panneau s'ouvre : rien n'est encore écrit.
3. Lisez l'**état des équipes** : effectif au 1er janvier et ce qu'il manque pour armer le FPT. L'appli signale seulement ; pour ajuster, allez dans Agents ou Nominations.
4. Lisez le **roulement et les fêtes** : qui tient Noël et le Nouvel An, et les semaines changées pour cela. Si le tour est impossible, le panneau le dit et donne le compromis.
5. Ouvrez les **manœuvres reprises** : même place dans le mois, même heure, même thème, même lieu. Les annulées ne reviennent pas.
6. Lisez le **résumé**, puis « Accepter et écrire le brouillon », ou « Non merci ».
7. Retouchez les étapes si besoin, saisissez les vacances scolaires à l'étape Repères, puis publiez à l'étape « Vérifier et publier ». Avant, les agents ne voient rien et aucune manœuvre n'est annoncée.

Une année qui a déjà un roulement n'est jamais écrasée : le bouton n'apparaît plus.
