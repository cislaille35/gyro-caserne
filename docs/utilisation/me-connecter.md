# Comment me connecter ?

Pas de mot de passe : l'appli vous envoie un courriel, avec un code à 6 chiffres et un lien.

1. Ouvrez Gyro Caserne, tapez votre adresse e-mail, puis appuyez sur « Recevoir un lien de connexion ».
2. Ouvrez le courriel « Connexion à Gyro Caserne » (regardez aussi dans les courriers indésirables).
3. Deux façons de vous connecter, au choix :
   - tapez le **code à 6 chiffres** dans l'appli, sur la page « Lien envoyé », puis appuyez sur « Me connecter » ;
   - ou ouvrez le **lien**.

Le code et le lien valent 5 minutes, une seule fois. Trois codes faux et le code ne marche plus.

## Sur iPhone, avec l'appli installée

Tapez le **code** dans l'appli. Le lien s'ouvrirait dans Safari : il connecterait Safari, pas l'appli installée.

## Le courriel n'arrive pas, ou le code ne marche plus

Appuyez sur « Renvoyer l'e-mail » : un courriel par minute au plus. Seul le dernier code reçu marche. Rien n'arrive ? Votre adresse n'est peut-être pas celle que le centre connaît : demandez au chef de centre.
