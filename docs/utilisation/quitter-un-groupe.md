# Comment quitter un groupe ?

Ouvert à tout membre d'un groupe de la messagerie.

1. Appuyez sur « Échanges », puis sur « Messages », et ouvrez le groupe.
2. Appuyez sur le nom du groupe, en haut : ses infos s'ouvrent (à droite de la conversation, sur ordinateur).
3. Appuyez sur « Quitter le groupe ».
4. Confirmez avec « Quitter le groupe ». Vous revenez à la liste des messages.

Vous ne lisez plus ses messages. Pour revenir, un animateur du groupe doit vous ajouter. Si vous étiez le dernier membre, le groupe est effacé.
