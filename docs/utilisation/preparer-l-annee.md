# Comment préparer le planning de l'année ?

Ouvert au chef de centre et à son adjoint (droit « Gérer le planning »).

1. Appuyez sur « Planning », puis sur « Préparer l'année ». Choisissez l'année en haut.
2. **Roulement** : choisissez l'équipe de chaque rang (la 1re tient la première semaine), puis « Enregistrer le roulement ».
3. **Semaines** : ouvrez un mois, changez l'équipe d'une semaine si besoin, puis « Enregistrer les semaines ».
4. **Noël et Nouvel An** : vérifiez l'équipe de chaque fête. Un message dit si elle passe hors de son tour. Saisissez une fois les années passées dans « Historique ».
5. **Manœuvres** : « Ajouter une manœuvre », remplissez la date, l'heure, le thème, le lieu, les équipes, le petit-déjeuner, puis « Ajouter la manœuvre ».
6. **Repères** : ajoutez les vacances scolaires (nom, du, au).
7. **Publication** : appuyez sur « Publier l'année ». Avant, les agents ne voient rien.

Après la publication, tout changement est visible tout de suite. Une manœuvre déjà annoncée sur « Le centre » se modifie ou s'annule depuis sa page : les convoqués sont prévenus.
